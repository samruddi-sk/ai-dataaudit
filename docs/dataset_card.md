# Dataset Card: UCI Online Retail II

- Source: UCI Machine Learning Repository, dataset ID 502.
- Dataset page: https://archive.ics.uci.edu/dataset/502/online+retail+ii
- Citation: Chen, D. (2012). Online Retail II. UCI Machine Learning Repository. DOI: https://doi.org/10.24432/C5CG6D
- License: The UCI page lists CC BY 4.0; verify the current terms before redistribution.
- Intended use: Research prototype for claim verification under data-quality defects.
- Limitations: This is transactional retail data. The cleaning pass does not establish perfect ground truth; it creates a documented reference baseline. Synthetic injected defects do not represent the full complexity of naturally occurring data-quality problems.
- Sensitive data: Inspect fields and usage terms before public release; do not infer identities or publish customer-level data unnecessarily.
